# 🌡️ React + Tailwind Dashboard за Arduino Термометър

Уеб-базирано потребителско табло за визуализация на **температура и влажност в реално време**, получавани от **Arduino + DHT11/DHT22 сензор**, свързани чрез **сериен порт (Web Serial API)**.

Проектът комбинира:
- ⚛️ React (TypeScript)
- 🎨 Tailwind CSS + shadcn/ui
- 🔌 Arduino (C++)
- 📡 Serial комуникация в JSON формат

---

## 🚀 Основни функционалности

- 📈 Реално време визуализация на температура и влажност  
- 🔥 Хардуерна аларма (зумер + LED) при температура над 28°C  
- 🚨 Визуална аларма в UI при критична температура  
- 📊 Температурна история (мини графика)  
- 💧 Прогрес бар за влажност  
- 🔌 Свързване към Arduino директно от браузъра (без бекенд)

---

## 🧠 Архитектура

 Arduino (DHT11/DHT22)  
↓ Serial (JSON)  
Browser (Web Serial API)  
↓  
React Dashboard (Tailwind UI


Arduino изпраща данни в JSON формат през `Serial`, които React приложението парсва и визуализира.

---

## 🔌 Arduino Част

### 📦 Необходими компоненти
- Arduino Uno / Nano / Mega
- DHT11 или DHT22
- Зумер
- LED + резистор
- Jumper кабели

### 🧷 Свързване
| Компонент | Пин |
|---------|-----|
| DHT Data | D2  |
| Зумер / LED | D8 |
| VCC | 5V |
| GND | GND |

### 📟 Arduino код
- Чете температура и влажност на всеки 2 секунди
- Активира аларма при **T > 28°C**
- Изпраща данните като JSON:
``
{
  "temp": 24.5,
  "hum": 60,
  "alarm": false
}
``

## ▶️ Стартиране на проекта

### 1️⃣ Инсталиране на зависимостите

`npm install` 

### 2️⃣ Стартиране на dev сървър

`npm run dev` 

### 3️⃣ Свързване с Arduino

1.  Качи Arduino кода на платката
2.  Включи Arduino към USB
    
3.  Отвори приложението в браузъра
    
4.  Натисни **„Свържи устройство“**
    
5.  Избери правилния COM порт
